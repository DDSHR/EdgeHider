# EdgeHider 展示素材

所有窗口与便笺内容均为虚构，非实机截图或录屏，不含用户桌面或个人数据。使用项目原有 AppIcon.png 图标，素材随项目采用 MIT 许可证。

- cover.png：GitHub 首页封面（1280 × 720）
- edge-hide-demo.gif：隐藏 → 悬停唤回 → 操作 → 移开收起的循环示意（960 × 540，8 秒）
- workflow.png：三步操作流程（1280 × 720）
- features.png：功能概览（1280 × 720）
- social-preview.png：分享预览图（1280 × 640）
- demo-poster.png：动画静态预览（960 × 540）

示意动画不代表实际动画时序或兼容性，也不表示已支持其他应用原生全屏 Space 内的真实窗口操作。

使用 Python 3 与 Pillow 运行 `Tools/generate_showcase.py` 可重新生成；默认字体来自 macOS。分享预览图可用于仓库 Settings → General → Social preview。
